# What's For Dinner

Can't decide what to cook? One click picks a random recipe from a built-in collection and shows everything you need at a glance.

**Live demo:** https://yosef-tamer206.github.io/What-s-For-Dinner/

## Features

- Random meal suggestion from a built-in collection of 13 recipes
- Recipe card with photo, rating and review count
- Prep time, cook time, servings, difficulty level and category
- Chef tips for every recipe
- Automatic warning badge when total time exceeds 45 minutes

## Tech Stack

- HTML5, CSS3, vanilla JavaScript
- Bootstrap 5
- Font Awesome icons

## Run Locally

```bash
git clone https://github.com/Yosef-Tamer206/What-s-For-Dinner.git
cd What-s-For-Dinner
```

Open `index.html` in a browser.

## Notes

- Recipes are bundled in `js/main.js`; no external API is used.
